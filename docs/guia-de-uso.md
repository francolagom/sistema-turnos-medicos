# Guía rápida de uso

1. Ingresar con el usuario administrativo.
2. Desde **Pacientes**, registrar las personas que solicitan atención.
3. Desde **Médicos**, registrar profesionales y especialidades.
4. Desde **Horarios**, definir los días, rangos de atención y duración de los turnos de cada profesional.
5. Desde **Turnos**, seleccionar **Asignar turno**, elegir médico y fecha, consultar horarios libres y guardar la reserva.
6. Para corregir una reserva, seleccionar **Modificar**. Para anularla, seleccionar **Cancelar**. El horario cancelado vuelve a estar disponible.
7. Desde **Inicio**, consultar un resumen y los turnos previstos para el día actual.

Los campos marcados como obligatorios deben completarse. El sistema no permite asignar fechas pasadas ni reservar un horario que no pertenezca a la agenda configurada.
